# SteedAtlas · 百骑谱 | Public Engineering Showcase

**Evidence-first RAG, source provenance and bounded Research tools · Synthetic, offline, executable demonstration**

> 本目录公开的是百骑谱私有项目的**独立技术缩小版**：不是私有仓库镜像，不包括原站源码、账号/订单数据库、旧版图片、私人 Git 历史或原始史料缓存。全部示例马名、作品与文献均为**合成测试数据**，不是历史事实。

## 运行

仅需 Python 3.10+，无需安装依赖、联网或模型密钥。在该目录下执行：

```bash
python demo.py --query "赤云归属" --limit 2
python demo.py --query "玄驹故事" --scope literary
python demo.py --query "赤云" --agent
python -m unittest discover -s tests -v
```

## 技术展示

| 能力 | 本目录可核验的实现 |
| --- | --- |
| 中文检索 | 简繁/别名归一化、字符二元组 BM25 |
| 可追溯引文 | 文本 SHA-256、精确区间、版本、许可与可见性校验 |
| 证据冲突 | 同实体、同命题、相反关系优先进入有限 Top-k；报告被截断的反证 |
| 来源依赖 | 转载不算新的独立来源组 |
| 受控研究工作流 | 只读工具白名单、预算、错误轨迹、真实本地函数调用 |
| 拒答与体裁 | 文学材料独立筛选、无答案/特定关系拒答、不把引用当史实证明 |

本展示 **25 项本地合成回归测试通过**；不包含任何外部 LLM、Jev、向量数据库或 GPU 视频生成模型，也不对历史准确率作出承诺。代码为新编写的简化演示，不是旧网站源代码。

## 原项目成果与边界

原私有百骑谱项目在 2026-11-02 的本地验收记录中报告：100 项文化图鉴档案、22 个已取得许可的文献页面版本、其中 17 个版本具有有效引文、82 条机器核对的**原文提及关系**关联 32 个实体；独立 Windows/Python 3.13 环境记录 104 项后端测试通过。这些是**原完整项目的历史验收数据，不是当前简化演示代码的评测结果**；机器核验原文不代表事实真实性或专家审定。

原项目包括 FastAPI/SQLAlchemy 统一知识服务、版本化来源与引用、官方 API 的受限来源采集、规则 Research 工具链、持久化任务 DAG 和 FFmpeg CPU 视频导出。当前主要回答模式是检索与归属式摘要，不是完整 LLM 多智能体系统。此目录只复现其中精确引用、检索、冲突和工具权限等可公开部分。
