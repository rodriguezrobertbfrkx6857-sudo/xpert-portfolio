**25 synthetic fixture unit tests passed** locally using the checked-in `demo.py` and `tests/test_demo.py`. This verifies the behavior of this tiny code example, not the full private application.

## Original project historic acceptance (2026-11-02)

The private project recorded 100 edited cultural catalogue entries; 22 acquired, license-checked source page revisions; 17 revisions with usable excerpts; 82 machine-verified **mentions** across 32 catalogue entities; and a 104-test Windows/Python 3.13 backend acceptance run. These values belong to a saved local snapshot, not to this synthetic demo. They do not show independent historical accuracy or expert-reviewed facts.

The private version also has a FastAPI/SQLAlchemy unified knowledge interface, constrained official source acquisition, rule-governed research tools, and a persistent DAG with FFmpeg CPU video output. The current synthetic demonstration does **not** include this full stack. Neither repository claims tested LLM, Jev, dense retrieval, or autonomous model reasoning.
