# Resume-safe summary

**百骑谱（SteedAtlas）——可溯源知识检索与受控 Research 工作流平台**

原项目通过 FastAPI/SQLAlchemy 将文化图鉴、知识检索、问答与创作模块连接到同一证据服务；基于中文别名和 BM25 排序、版本/哈希/原文片段校验，构建可追踪的引用流程；提供规则调度的 Research 工具和持久化 DAG、FFmpeg CPU 视频导出。

2026-11-02 的原项目验收快照记录：100 个文化档案条目，22 个许可页面修订，82 条机器核对的原文提及关系覆盖 32 个实体，以及 104 项后端测试通过记录。**不能称为 82 条经确认的历史事实，也不能将本公开示例的测试结果与私有全栈测试混淆。**
